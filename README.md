# Story Board

A full-stack web application for creating, browsing, and voting on short stories.

## Live Demo

https://story-board-seven.vercel.app/

## About the Project

Story Board is a personal project built to practice modern full-stack web development with Next.js, TypeScript, API routes, and MongoDB.

The app allows users to view story posts and interact with them through voting functionality. The goal of the project was to build a clean, structured, and deployable web application using a real database and production deployment workflow.

## Tech Stack

- Next.js
- React
- TypeScript
- MongoDB
- CSS
- Vercel

## Features

- Browse story posts
- Vote on stories
- API routes for story data
- MongoDB database connection
- Responsive web interface
- Deployed on Vercel

## What I Practiced

- Building a full-stack app with Next.js
- Working with TypeScript in a React project
- Creating API routes
- Connecting a frontend app to MongoDB
- Handling dynamic routes
- Deploying a project to Vercel
- Debugging real-world frontend/backend issues
